# FitFlow – Fitness Application Redesign

FitFlow is a redesigned fitness application focused on personalized workout recommendations, nutrition tracking, and social fitness features.

## Project Overview

The FitFlow redesign aims to provide users with a simple, user-friendly and scalable fitness platform that supports mobile and web applications.

The system includes personalized workout recommendations, nutrition tracking, social sharing and AI-powered fitness features.

## Technology Stack

### Frontend
- React Native
- TypeScript
- Web support

### Backend
- Node.js
- Express.js

### AI Service
- Python
- FastAPI

### Databases
- PostgreSQL
- Firebase Firestore
- Redis

### Authentication
- Firebase Authentication

### Storage
- Cloud object storage such as AWS S3

## Main Features

- Personalized workout recommendations
- User fitness profile
- Workout tracking
- Nutrition tracking
- AI-powered recommendations
- Social fitness sharing
- Realtime updates
- Secure user authentication
